# R-001：计划内无依赖步骤并行执行

> 使用说明：草案阶段由助手根据七问整理；确认后把状态改为 `confirmed`。

- 状态：implemented（2026-11-24，SA-07A～E）
- 优先级：P1
- 提出人 / 日期：用户 / 2026-11-23
- 决策人：用户
- 关联任务：SA-07
- 关联 ADR：ADR-010（并行执行）

## 1. 背景与问题

当前子 Agent 的计划执行是严格串行：`executePlan` 按 `plan.steps` 顺序逐条调用工具，8 步计划、12 次工具调用、单次 60 秒与整次 180 秒预算共同约束。复杂问答需要多关键词、多课程、多来源检索时，串行累加很容易顶到 180 秒上限；治理批量扫描同样逐目标串行，吞吐受限。

## 2. 目标与场景

- 问答/RAG：学生提出跨教材、跨课程的复杂问题时，多个互不依赖的只读检索同时发出，而不是排队累加。
- 治理批量扫描：同一轮内多个内容目标的读取与初筛可以并发，缩短一轮耗时。
- 可观测结果：同一组检索在串行与并行两种执行下对比 p95 耗时，并行显著更低，且工具调用总数不增加。

## 3. 范围（做）

1. 计划内依赖分析：解析步骤参数中的 `$sN` 引用，只有不引用前序结果的步骤允许并发。
2. 并发执行只读低风险步骤：设置单计划并发上限（默认 4），超出的步骤排队。
3. 实例级在途调用总上限：进程级信号量兜底，避免 8 个槽位各自并发叠加打爆后端。
4. 预算原子扣减：并发下总工具调用仍不超过 12 次，不超发。
5. 失败语义沿用现有实现：普通工具失败记入 `failures` 并继续；401/403、策略错误、取消终止全部在途调用。
6. 审计按 `stepId` 归属记录，兼容并发完成顺序不确定。

## 4. 非范围（不做）

以下四项登记到**下期计划**，本期不实现：

1. 多子 Agent / 跨 job 并行（一个 job 仍只占一个槽）。
2. 写操作与审批类步骤并行（`propose*` 保持串行）。
3. 并发度自适应（固定上限，不做动态升降）。
4. 修改预算与恢复机制（60 秒 / 180 秒 / 12 次 / 1 次返工不变，不新增进程重启恢复）。

## 6. 约束

- 性能与延迟：单次上游调用 60 秒、整次运行 180 秒不变，并行只压缩时延。
- 并发与容量：单计划并发默认 4；实例级在途总上限默认 8～12（待定）；默认值按 4C4G 设定。
- 安全与隐私：只允许 `riskLevel=low` 且只读的工具并发；身份字段拒绝规则、任务范围断言不变。
- 成本：总工具调用上限 12 次不变，返工不重置预算。
- 部署与兼容：通过开关与环境变量控制，未开启时保持现有串行行为。

## 7. 依赖与风险

- 依赖的数据 / 接口 / 外部服务：后端 `/internal/agent/*` 内部接口的并发容量；审计写接口的吞吐。
- 最大未知：后端并发实测容量未知，信号量默认值可能偏大或偏小。
- 失败回退或降级：通过环境变量关闭并行，回退到串行执行；后端出现 429 时按调用失败处理，不在 Agent 侧重试。

## 8. 优先级与决策

- 优先级理由：不阻塞已有功能，但直接影响复杂问答体验与治理扫描吞吐；用户确认“下一步就做”。
- 发布阻塞关系：不作为当前发布阻塞项。
- 谁确认：用户。
- 可延期项：非范围四项均为下期计划，不影响本期验收。

## 9. 可行性初判（助手填写）

- 现有能力与限制：执行器串行循环；参数引用语法已限制为纯 `$sN` / `$input` 路径，依赖可静态判定；预算 `consume()` 非原子；审计按序写入。
- 可选方向：A 计划内步骤并发（只改执行器与预算）；B 一个 job 拆多个子 Agent（需重定义槽位计费、让位与检查点）。
- 推荐最小切片：A，B 与其余三项登记下期。
- 需要先验证的假设：依赖分析可在静态阶段完成；后端能承受默认并发值；并发审计可按 stepId 追溯。

## 11. 交付反馈

- 验收项结果：1～6 由 `agent/tests/plan-parallel.test.ts` 11 项覆盖；第 7 项由 `npm run bench:plan-parallel` 输出，p95 1025.1ms → 259.7ms，下降 74.7%。
- 证据：`agent/tests/plan-parallel.test.ts`、`agent/tests/runtime-config.test.ts`、`backend/tests/test_plan_parallel_setting.py`、`docs/审查记录/计划内并行/SA-07C-07E.md`。
- 未验证：真实后端并发容量、真实模型下的端到端时延、生产环境开启后的稳定性。
- 变更与决策：全局开关存 `system_settings`，仅管理员可写；Agent 30s TTL 读取，失败沿用缓存/默认关闭；前端设置页下期接入。
- 风险与回退：生产开启前按 4C4G 实测复核默认并发；异常时管理员关闭开关或设置 `PLAN_PARALLEL_ENABLED=false` 回退串行。
