# ADR-001：阶段范围与分期

- 状态：accepted
- 日期：2026-09-20（2026-10-06、2026-11-21 修订）
- 决策人：用户
- 取代：旧 Q-08“本期只做业务后端”范围注
- 被取代：无

## 背景

项目包含业务后端、前端、Agent 三个服务。早期为控制范围，规定一期只做业务后端，Agent 与前端页面后置。后续二期启动后，旧范围注与代码状态不一致，出现多处“已实施/未实施”并存。

## 决策

- 一期（T-01～T-10）：业务后端为主，前端与 Agent 不阻塞一期验收。
- 二期（T-11～T-17）：Agent 服务、治理逻辑、前端页面与 Agent 相关能力分批实施；前端 F-C1～F-C5 已完成，F-C6 待完成。
- 三期（T-18～T-20）：部署、验收与收口。
- 业务事实与授权只来自 FastAPI + MySQL；Agent 只能调用 `/internal/agent/*` 白名单接口。
- 历史 Q-08 表述不再作为当前范围依据；当前进度只看 `specs/status.md`。

## 后果

- 旧文档中的“只做后端/Agent 不搭建”需要按当前状态覆盖，避免四处口径不一致。
- 阶段验收以任务勾选和 `status.md` 为准，不以某一份范围注为准。
