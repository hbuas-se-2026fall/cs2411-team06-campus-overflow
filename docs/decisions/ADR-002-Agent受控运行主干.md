# ADR-002：Agent 受控运行主干

- 状态：accepted
- 日期：2026-10-22（2026-11-21 补注）
- 决策人：用户
- 取代：旧 `agent-loop.ts` 作为 HTTP 入口的做法
- 被取代：无

## 背景

Agent 需要可审计、可取消、可复核地执行模型计划与工具调用，不能只依赖一次性模型输出。G-01～G-06 授权了受控运行主干。

## 决策

- 聊天与四类任务统一经 `loop/planned-tools.ts` 生成并执行模型计划；运行预算跨计划累计。
- 生产入口使用请求级持久记录器，计划、调用准备、调用完成追加到后端；记录失败阻断后续模型/工具，终态审计失败不返回成功。
- 运行取消与超时由 `loop/run-control.ts`、`loop/abort.ts` 管理；模型、工具、后端 HTTP 共享运行信号，取消/超时不重试或降级。
- `loop/reviewed-run.ts` 统一结果来源检查、无工具模型审查与一次返工；权限、审计、取消错误不返工。
- 原文与审查内容不写入审计，只留摘要。

## 后果

- 旧 `agent-loop.ts` 仅用于辅助测试，不作为 HTTP 入口。
- G-06 真实模型与真实 MySQL 联调仍未完成；不能以单元测试宣称真实效果通过。
