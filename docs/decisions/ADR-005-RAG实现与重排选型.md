# ADR-005：RAG 实现边界与重排选型

- 状态：accepted
- 日期：2026-11-21
- 决策人：用户
- 取代：早期“暂不采用 HNSW”“精排后续选型”的表述
- 被取代：无

## 背景

RAG 需要从课程知识卡片中召回证据。早期设计对 HNSW、重排模型与实现范围存在分歧；用户明确 RAG 要实施，不是可选扩展。

## 决策

- 混合召回：HNSW 稠密召回 + BM25 关键词召回，RRF 融合。
- 重排复用现有 OpenAI 兼容 `/rerank` 服务（D-033），不引入本地 Cross-Encoder 运行时。
- 选择链路：20 召回 → 卡片去重 → 候选 5 → 精排 → 阈值 → 3 条 → 2400 字总预算；不足 3 条不强凑。
- 精排失败回退 RRF；调用方取消则终止，不降级；默认关闭。
- D-022：每条证据同时返回卡片摘要与定位正文。
- 子问题按标点与连接词确定性拆解，最多 4 个；每个子问题独立召回与精排，合并时轮转并去重。
- 概念扩展第一版用共享受信标签做 1 跳，并标注 `relation`。
- 真实 embedding、50 题标注、阈值校准与拒答不在本决策内，仍未完成。

## 后果

- 管线可运行，但不能宣称效果优于基线；默认关闭，需显式配置。
- 需要真实 rerank 服务测量 P95 延迟与费用。
- 早期“暂不采用 HNSW”作废，以本 ADR 为准。
