# ADR-007：部署目标（腾讯云 4C4G + 已备案域名）

- 状态：proposed
- 日期：2026-11-21
- 决策人：用户
- 取代：InstaBox 作为主部署目标的设想
- 被取代：无

## 背景

项目需要长期在线的演示与验收环境。InstaBox 是 Agent 云机器，存在自动暂停、按时计费、无托管数据库等限制；用户已有腾讯云 4C4G 服务器与已备案域名。

## 决策

- 目标环境：腾讯云 4C4G，CentOS/TencentOS，已备案域名。
- 采用 Docker Compose 部署 MySQL、FastAPI、Next.js、Agent；Nginx 作为唯一公网入口，只开放 80/443。
- 增加 4 GB swap；MySQL 限制内存；Next.js/Agent 镜像在本地或 CI 构建，服务器只拉取运行。
- MySQL 与 MCP 仅容器内网；备份使用 `mysqldump --single-transaction` + 上传目录打包。
- 证书优先使用腾讯云免费 SSL，Nginx 配置 SSE 关闭缓冲。

## 后果

- 该决策尚未生效：frontend/agent Dockerfile、生产 Compose、Nginx 配置、迁移与备份脚本均未落地，也未在目标服务器验证。
- 4C4G 资源紧张，构建与运行需分离；生产可用性、监控与多实例仍未验收。
