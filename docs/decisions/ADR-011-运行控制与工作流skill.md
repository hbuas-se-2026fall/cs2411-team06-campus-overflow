# ADR-011：运行中人工控制与工作流 skill 沉淀

- 状态：accepted
- 日期：2026-11-25
- 决策人：用户
- 关联：spec RC-R01～R05 / SK-R01～R05、plan AX-R11、requirements/R-002

## 背景

治理任务在审批通过后长时间自动运行，管理员发现方向偏差时只能等待或取消；同类任务每次都重复检索与推理，token 与耗时高。现有审批等待只支持“等待—恢复/取消”，现有 `main-context` skills 是手工维护的受控文件，没有管理端增删与版本控制。

## 决策

1. **控制状态归后端**：新增运行控制状态与命令表，以 `revision` 递增 + `ack` 保证跨实例只消费一次；Agent 只在 step/工具边界拉取并跟随，不在本地持有权威状态。
2. **边界暂停**：暂停不中断已发出的模型请求；当前 step 结束后停在下一步模型调用前，保留槽位租约最多 30 分钟，超时自动取消并释放。
3. **引导词低优先级注入**：引导作为独立段落注入下一次模型 prompt，明确不得扩大工具与角色权限；审计只存摘要与 digest，正文消费后清空。
4. **skill 存后端并版本化**：`workflow_skills` + `workflow_skill_versions`，发布生成新版本并固定 current_version；运行中读取固定版本，避免半更新。
5. **AI 只提案、管理员发布**：任务结束生成 draft，管理员编辑发布；删除为归档，不影响历史运行。
6. **注入有预算**：每次最多 3 条、4000 字符、额外 token 默认 1500；超限截断并记录；`SKILL_INJECTION_ENABLED` 与 `RUN_CONTROL_ENABLED` 默认关闭。
7. **收益门槛**：20 条固定治理样本，重复检索 -50%、输入 token -30%、成功率不降、P95 不劣化，才允许默认开启注入。

## 后果

- 正面：管理员可及时纠偏而不整次重跑；同类任务复用路径，降低 token 与耗时；控制与沉淀均可审计、可回滚。
- 负面：暂停期间占用槽位可能造成排队；需要新增两张控制表与两张 skill 表，并扩展管理端页面；skill 可能过时，需要定期清理与版本停用。
- 边界：不中断已发出的模型请求；不覆盖学生/教师会话；skill 不构成授权；多实例崩溃不承诺续跑，超时转取消以避免重复执行高风险动作。

## 备选方案

- 只在 Agent 内存保存暂停状态：多实例不一致，否决。
- 暂停立即中断模型流：实现复杂且会产生半截输出，否决。
- AI 自动发布 skill：易沉淀噪声且难以追责，否决。
- skill 存在 Markdown 目录：无法做版本、权限与审计，否决。

## 后续

- 由 T-21/T-22 实施；量化未达标时保持开关关闭，回到现状行为。
- 本 ADR 不取代既有 ADR-004（个人记忆隔离）与 ADR-010（计划内并行）。
