# ADR-004：个人记忆按账号在浏览器隔离

- 状态：accepted
- 日期：2026-10-29（2026-11-21 补注）
- 决策人：用户
- 取代：旧后端 `agent_memory` 作为个人记忆主方案
- 被取代：无

## 背景

个人记忆涉及隐私。早期方案由后端 memory 表承担，但用户明确要求按账号隔离、保存在浏览器、可清空，不提供云同步或读取他人记忆。

## 决策

- 学生/教师个人记忆保存在浏览器，按账号隔离，可查看、新增、删除、清空。
- 不提供云同步，不读取他人个人记忆。
- 管理员自己的记忆与会话使用服务器私有文件（GL-07），与中台接入会话分目录并做来源/客户端授权隔离。
- 旧后端 memory 表与接口只是历史基础，不代表当前个人记忆方案；不自动删除旧数据。
- 记忆写入必须做敏感过滤，不得保存密码、密钥、隐私原文；浏览器内容不得作为后端授权依据。

## 后果

- Agent 不能把个人记忆当作访问凭证。
- T-14 的 M-03（自动更新）与 M-04（旧 memory 清理）仍未完成。

> 2026-11-24 进展：M-03（AI 候选 + 浏览器确认写入 + 开关）与 M-04（删除旧 `/internal/agent/memory` 与 `agent_memory` 表）已完成；本 ADR 决策不变，证据见 `specs/tasks.md` 与 `docs/审查记录/收尾/M-03-Scan-T17.md`。
