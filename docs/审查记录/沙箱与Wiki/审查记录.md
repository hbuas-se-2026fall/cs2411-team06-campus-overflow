## 决策与限制

- dry-run 采用只读影响统计，不执行后回滚：避免误触通知、缓存与外部副作用；代价是统计口径是“预计影响”，不是数据库级真实回滚结果。
- 测试沙箱默认不映射外网，MySQL/Postgres 只用于本地与 CI；不注入生产凭证。
- MCP 沙箱解决执行环境隔离，不解决动作授权；生产出站网络白名单与 secret 注入仍需编排层完成。
- 本机 Docker Desktop Linux engine 未能启动，真实 MySQL 并发用例未执行；GitHub 网络当前不可达，Wiki 未推送远端。两者均保留为待执行验证，不勾选为已完成效果。
