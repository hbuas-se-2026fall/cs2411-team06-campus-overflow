# T-23F 入口保护与热点读缓存

日期：2026-11-28
范围：ADR-014 / T-23E 后续优化

## 设计依据

- 用户确认：本期不做异步化；先做入口保护、慢查询定位、进程内只读缓存，再复测 1000 并发。
- `docs/decisions/ADR-014-入口保护与读缓存.md`。
- `/api/courses` 已有批量查询（教师名、成员数、joined 均非 N+1），因此优先缓存核心只读数据，而不是改查询。

## 实现

- `backend/app/core/cache.py`：线程安全 TTL + LRU，`get_or_set/clear/stats`，无第三方依赖。
- 课程列表：缓存 `(page, page_size, keyword, semester)` 的核心数据；`joined` 每次实时查，`mine` 不走共享缓存。
- 标签：`(keyword, hot)` 缓存；榜单：`(period, course_id)` 缓存；TTL 均 30s。
- `app/main.py`：anyio 同步线程配额 200/worker（`BACKEND_THREADPOOL_TOKENS`）。
- `docker-entrypoint.sh`：uvicorn `--backlog 4096`。
- `deploy/nginx/default.conf`：`/api/` 每 IP `limit_conn 1000`、`limit_req 1000r/s burst=2000`；`/internal/` 拒绝；429/503 JSON。
- `deploy/docker-compose.prod.yml`：新增 nginx 服务，`NGINX_PORT` 默认 8080。

## 验证记录

- 新增缓存与 worker 测试 16 项通过；相关回归 183 passed / 9 skipped；`ruff`、`lint-imports` 通过。
- 100 并发（10s）：100% 成功，P95 700.6ms，RPS 376.9。
- 1000 并发（60s，5 worker、200 线程、100 连接）：

```
total=13139 rps=168.4 success=9971 success_rate=75.89%
p50=683.8ms p95=30021.7ms
statuses=network_error:1535, 200:9971, 503:1633
```

- 1000 并发（30s，把连接池提高到 150）：成功率 65.22%，P50 4599.9ms，反而更差，确认瓶颈不是连接数。
- Nginx：`docker compose config --quiet` 退出码 0；`nginx -t` 未能执行（本机 Docker 守护进程未启动），运行时限流未验证。

## 结论

- 入口保护与缓存已落地，100 并发达标且无 503；1000 并发仍未达到 99%/1s，主要受同步线程模型与数据库队列限制。
- 缓存只能降低热点读的数据库工作量，不能把同步请求模型扩展到 1000 并发。
- 下一步必须异步化或水平扩容；建议单独立项，不在本次修复中继续调参。
- 未验证：Nginx 实际 429/503、真实 4C4G 容器、多实例缓存一致性。

## 2026-11-28 压测口径修正（keep-alive）

原脚本每个请求使用 `Connection: close`，1000 并发会制造 1000 次 TCP 建连/关闭，部分超时来自客户端与端口池。已改为每个 worker 复用一条 keep-alive 连接，按 Content-Length/chunked 读完响应，并增加预热。

复测（5 worker、200 线程、100 连接、缓存开启）：

| 并发 | 成功 | 成功率 | P50 | P95 | 断连 | 503 |
| --- | --- | --- | --- | --- | --- | --- |
| 10（5s） | 3442 | 100% | 7.7ms | 31.5ms | 0 | 0 |
| 100（15s） | 10674 | 100% | 125.6ms | 271.7ms | 0 | 0 |
| 1000（60s） | 24623 | 83.01% | 1038ms | 6290ms | 0 | 5039 |

- 1000 并发不再出现客户端超时，全部失败为服务端 503（连接池等待 5s），说明入口/建连口径修正后，瓶颈收敛到数据库连接队列。
- 成功率由 75.89% 提升到 83.01%，P95 由 30s 降到 6.29s，但仍未达到 99%/1s。
- 下一步若要达标，应减少每请求数据库往返（用户态/成员关系短 TTL 缓存）或异步化；单纯加连接数已验证无效。
