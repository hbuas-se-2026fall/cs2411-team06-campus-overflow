## 实现

- `rag/types.ts`：片段、embedding、HNSW、检索与诊断类型。
- `rag/embedding.ts`：OpenAI 兼容 `/embeddings`，批量 32、超时 30 秒、条数/维度校验；`RAG_ENABLED` 默认关闭；错误不包含 API Key；`createHashEmbeddingProvider` 仅供 fixture。
- `rag/hnsw.ts`：纯 TS 内存 HNSW，余弦 + L2 归一化；默认 M=16、efConstruction=200、efSearch=64；固定种子可复现。
- `rag/tokenize.ts` + `rag/bm25.ts`：中文双字 n-gram、拉丁/数字标识符；BM25 k1=1.2、b=0.75；精确标识额外加权。
- `rag/index.ts`：HNSW 稠密召回 + BM25 关键词召回 + RRF（k=60），默认 N=20、K=5；课程过滤；候选数超过默认 efSearch 时自动放大。
- `rag/catalog-source.ts`：摘要一个片段；正文按空行分段，默认 1200 字符，超长硬切；沿用目录版本校验。
- `rag/eval.ts` + `scripts/rag-eval.mjs` + `eval/rag-fixture.json`：Recall@K/N、全证据召回、零召回、MRR、无答案命中、P95；`npm run rag:eval` 跑 fixture。
- `rag/runtime.ts`：按课程缓存索引，缓存键为“目录版本 + embedding model + baseUrl”；并发构建复用 Promise；失败只记录脱敏摘要并返回 `undefined`。
- `tools/search-knowledge.ts`：`RAG_ENABLED=true` 且有 `courseId` 时注册 `searchKnowledge`；课程闭包绑定、入参 `.strict()`、执行前用用户凭证 `fetchTrustedTags` 复核课程资料权限、正文截断 800 字、检索异常降级为空结果；已加入 `COMMON_READ_TOOLS` 供 chat 规划使用。

## 决策说明

- **纯 TS HNSW 而非引入原生库**：避免 Windows/CI 原生编译与 WASM 依赖，索引可重建、可测试；代价是性能未与成熟库对比，规模面向 1～10 本教材。
- **中文双字 n-gram 而非 jieba**：不引入原生分词依赖，错误码/版本号按拉丁 token 原样保留；代价是长词切分粒度较粗，语义质量待真实语料验证。
- **RRF 不混加原始分数**：遵循 D-024，避免 BM25 与余弦量纲不可比；参数 k=60 为初始值。
- **课程过滤在召回后执行**：HNSW 不支持元数据过滤；先放大候选再过滤，避免过滤后不足 N。
- **默认关闭**：`RAG_ENABLED=false`，不改变现有问答链路；未配置真实凭证时不会发起网络请求。
- **课程在工具闭包绑定**：`searchKnowledge` 入参不允许 `courseId`，避免模型通过参数扩大课程范围；检索层再做一次课程过滤。
- **运行时懒构建并按版本缓存**：不在进程启动时预构建，避免无请求时消耗 embedding 额度；目录版本或 embedding 配置变化才重建。
- **失败降级为空结果**：教材索引构建/检索失败只记录脱敏摘要，工具返回 `degraded`，模型可回退课程卡片或普通问答，不阻断整轮对话。
- **fixture 用哈希向量**：保证测试确定、无网络依赖；明确不用于效果结论。
